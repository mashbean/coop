# 台灣繁體中文語言規範

- Coop、ROOST、Item、Item Type、Signal、Job 與 Queue 第一次出現時保留英文
- `review` 涉及內容個案時譯為「審查」，再次確認決定時譯為「複核」
- `moderation` 依語境譯為「內容治理」或「內容審查」
- `enforcement` 譯為「處置」，談制度落實時可譯為「執行」
- `report` 由使用者提出內容問題時譯為「檢舉」，依法送交機關時譯為「通報」
- `appeal` 譯為「申訴」
- `reviewer wellness` 譯為「審查員身心健康」
- API、程式碼、欄位名稱、指令、檔名與專案名稱不翻譯
- 保留原文的不確定性、條件、責任歸屬與功能狀態
- 美國或歐盟制度不得直接描述為台灣義務

台灣補充應使用獨立段落，並附官方來源、查核日期與適用限制。尚未完成法律或領域審查時，不提供確定性的法遵結論。
