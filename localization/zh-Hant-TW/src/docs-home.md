# 文件入口

歡迎閱讀 Coop 文件。原始碼與專案資訊見 [GitHub 上的 Coop](https://github.com/roostorg/coop#readme)。

文件依讀者身分與需求分成幾份指南。

- [繁中使用者指南](user/README.md)：了解 Coop、功能與使用者介面
- [英文開發指南](https://roostorg.github.io/coop/latest/development/)：執行 Coop 並了解程式碼結構
- [英文 API 參考](https://roostorg.github.io/coop/latest/api/)：Coop API 技術參考
- [英文整合指南](https://roostorg.github.io/coop/latest/integrations/)：內建整合的詳細資訊

請注意，官方文件有版本區分。其他版本可從[官方文件網站首頁](https://roostorg.github.io/coop/)取得。本繁中版本則以 [`sources.tsv`](../sources.tsv) 記錄各頁所依據的英文 commit。

## 貢獻

Coop 是由 [ROOST](https://roost.tools) 與社群共同建立的開放原始碼專案。我們歡迎各種貢獻，也需要多元觀點與專業能力，一起建立更安全的網路空間。

若您剛接觸本專案，建議先進行下列事項。

- 閱讀[行為準則](https://github.com/roostorg/.github/blob/main/CODE_OF_CONDUCT.md)，了解社群標準
- 檢視所有 ROOST 專案適用的[貢獻指引](https://github.com/roostorg/.github/blob/main/CONTRIBUTING.md)
- 查看[專案看板](https://github.com/orgs/roostorg/projects/15)，了解待處理 issue、里程碑與優先順序

撰寫程式碼不是協助專案的唯一方式。審查 pull request、回答問題、提供回饋、籌辦或教授教學課程，以及改善文件，都是十分珍貴的貢獻。

### 回報問題

發現錯誤或有功能需求時，歡迎告訴我們。

- 搜尋[既有 issue](https://github.com/roostorg/coop/issues)，確認是否已有人提出
- 若是尚未提出的問題，請[建立新 issue](https://github.com/roostorg/coop/issues/new)

## 尋求協助

若需要 Coop 使用協助或希望取得聯繫，隨時歡迎採取下列方式。

- 與社群[發起 discussion](https://github.com/roostorg/coop/discussions)
- 加入 [Discord 伺服器](https://discord.gg/97GQqtNAkE)，與貢獻者、採用者及其他社群成員交流
